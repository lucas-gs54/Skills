# Skills

Repositório onde guardo as skills que uso no dia a dia para aumentar minha produtividade e extrair o máximo da IA.

As skills deste repositório seguem como base documentações, guias e boas práticas oficiais de modelos e plataformas como Anthropic, Google e OpenAI.

## Estrutura

- `Documentation/`: skills para documentação, escrita e geração de conteúdo.
- `Engineering/`: skills para prompt engineering, organização de contexto e melhoria de resposta.

## Objetivo

Centralizar skills reutilizáveis para acelerar tarefas, melhorar a consistência das respostas e organizar fluxos de trabalho com IA.
