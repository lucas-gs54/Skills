# lgs54-doc-optimizer

**Otimiza documentos Markdown existentes** — clareza, concisão, correção, legibilidade, consistência. Não altera fatos.

## Quando Usar

- README, CHANGELOG, guia ou doc técnico verboso, confuso, com erros ou inconsistente
- Refinar expressão mantendo sentido técnico intacto
- Padronizar terminologia, formatação, estilo

## Modos

`full` (padrão) · `conciseness` · `readability` · `correctness` · `consistency`
