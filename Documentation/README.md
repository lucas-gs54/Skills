# Documentation Skills

Skills de documentação, escrita e geração de conteúdo Markdown.

## Qual Usar?

| Precisa... | Use |
|------------|-----|
| Otimizar docs existentes (clareza, gramática, concisão) | [`lgs54-doc-optimizer`](lgs54-doc-optimizer/) |
| Criar/estruturar docs do zero (README, CHANGELOG, etc.) | [`lgs54-markdown-generation`](lgs54-markdown-generation/) |

## Padrão Comum

Todas seguem: `SKILL.md` (workflow) + `references/` (por tipo de doc) + frontmatter YAML + Quality Checklist.
