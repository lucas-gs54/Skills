# lgs54-skill-creator

**Cria, refina, estrutura, valida e otimiza skills no padrão lgs54** — workflow universal padronizado para o ecossistema.

## Quando Usar

- Criar skill nova do zero seguindo padrão do repositório
- Refinar/atualizar skill existente para compliance lgs54
- Estabelecer reference files ou padronizar arquitetura de skills
- Validar se skill existente bate com os standards
