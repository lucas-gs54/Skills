# lgs54-frontend-craft

**Frontend com craftsmanship profissional** — HTML semântico, acessibilidade real, design tokens, motion purposeful, CSS performático, componentes tipados e composáveis. Não é template genérico de IA.

## Quando Usar

- Buildar UI nova do zero com padrão profissional
- Revisar/refatorar frontend — detecta e corrige anti-patterns de IA
- Design system disciplinado (tokens, não magic numbers)
- Acessibilidade WCAG 2.2 AA baseline real
- Performance como feature (bundle budgets, INP < 100ms, CLS = 0)
