# lgs54-prompt-engineering

**Cria, analisa, otimiza, valida e adapta prompts** para ChatGPT, Claude e Gemini.

## Quando Usar

- Criar prompt do zero para qualquer plataforma
- Otimizar prompt que falha ou é inconsistente
- Adaptar prompt entre plataformas (ChatGPT ↔ Claude ↔ Gemini)
- Diagnosticar por que prompt falhou

## Plataformas

ChatGPT · Claude · Gemini (sempre identifica alvo antes de gerar)
