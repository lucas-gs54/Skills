# Engineering Skills

Skills de engenharia, prompt engineering, análise de código e arquitetura.

## Qual Usar?

| Precisa... | Use |
|------------|-----|
| Criar, otimizar, adaptar prompts (ChatGPT/Claude/Gemini) | [`lgs54-prompt-engineering`](lgs54-prompt-engineering/) |
| Análise profunda de código (bugs, arquitetura, perf, segurança) | [`lgs54-deep-code-analysis`](lgs54-deep-code-analysis/) |
| Buildar/revisar frontend com padrão profissional | [`lgs54-frontend-craft`](lgs54-frontend-craft/) |
| Reorganizar codebase bagunçado em estrutura modular | [`lgs54-project-modularization`](lgs54-project-modularization/) |
| Criar/validar skills no padrão lgs54 | [`lgs54-skill-creator`](lgs54-skill-creator/) |

## Padrão Comum

Todas seguem: `SKILL.md` (workflow) + `references/` (detalhes) + frontmatter YAML + Quality Checklist.
